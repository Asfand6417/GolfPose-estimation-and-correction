# Multiview Golf Swing Analysis and Correction using Deep Learning-based Pose Estimation

🚀 **Live Demo:** [Check out the live web app here!](https://asfand6417.github.io/Multiview-Golf-Swing-Analysis-and-Correction-using-Deep-Learning-Base-Post-Estimation/)

## Overview
A state-of-the-art multiview pose estimation system that analyzes your golf swing with surgical precision using deep neural networks (CNN-LSTM).

## Features
- **Pose Alignment:** Synchronized multiview processing for high-fidelity 3D body reconstruction.
- **Phase Detection:** Automatic identification of 8 critical swing phases.
- **Correction Logic:** Neural network-driven feedback system comparing stance against professional benchmarks.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Asfand6417/Multiview-Golf-Swing-Analysis-and-Correction-using-Deep-Learning-Base-Post-Estimation.git
   ```
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the analysis:
   ```bash
   python main.py
   ```
